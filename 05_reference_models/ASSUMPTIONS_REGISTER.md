# Assumptions Register

This register models the baseline dependencies required for the Material Dignity Infrastructure (MDI) to function. Assumptions are structural conditions treated as true for the purpose of architectural design. If any primary assumption is invalidated by field data, the interdependent Phase Zero clinical mechanics require immediate revision.
